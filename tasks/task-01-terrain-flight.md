实现本项目的第一个垂直切片：一个可在浏览器直接运行的超大尺度无限地形飞行原型。

## 产物

只创建这三个文件：

- `index.html` — 页面骨架、HUD、Three.js importmap
- `src/terrain.js` — 确定性地形高度场与地块网格生成
- `src/main.js` — 场景、相机、飞行控制、LOD 调度、预取、渲染循环

## src/terrain.js 必须导出

```js
export function createTerrain(worldSeed)
```

返回对象至少包含：

```js
{
  sampleHeight(worldX, worldZ),        // 确定性高度，单位米
  sampleNormal(worldX, worldZ, step),  // 由高度差分求法线
  buildTileGeometry(tileX, tileZ, tileSize, segments), // 返回 BufferGeometry
  LAYERS                               // 各层的波长与振幅常量，便于调参
}
```

`sampleHeight` 的实现要求：

1. 用基于 `worldSeed` 的整数哈希实现 value/gradient noise，**不使用 Math.random**。
2. 高度 = 宏观层 + 山脉脊线层 + 侵蚀近似层 + 细节层，四层振幅与波长按 AGENTS.md 的尺度规则设定。
3. 山脉脊线层必须用 ridged multifractal（形如 `1 - Math.abs(n)` 再取幂并逐层衰减），使山脊连续成脉、有主次层级，不能是一片孤立尖峰。
4. 侵蚀近似层要让陡坡处高频细节衰减、缓坡处保留沟壑走向。
5. 至少要能产生：一条延展超过 `100 km` 的巨型山脉带、一个纵深 `10 km` 量级的超级峡谷、一片 `100 km` 量级的高原。

## src/main.js 必须实现

1. **飞行控制**：WASD 控制推进与横移，鼠标控制朝向（pointer lock），`Shift` 加速，`Space`/`Ctrl` 升降。速度范围要能从 `100 m/s` 到 `20 km/s`，以便快速跨越超大尺度地形。
2. **LOD 调度**：以玩家为中心的分层地块环。近处地块小而密，远处地块大而疏，至少 6 个 LOD 层级，最远可见距离达到 `500 km` 量级。
3. **无缝拼接**：相邻 LOD 之间用裙边（skirt）或边缘顶点吸附消除裂缝，飞行时不能看到地形之间的黑色缝隙。
4. **预取**：根据当前速度矢量预测未来若干秒的位置，优先生成该方向的地块。生成任务分帧执行，单帧生成预算受限，避免卡顿。
5. **卸载**：超出范围的地块必须 dispose geometry 并移除，已加载地块数量要有上限。
6. **尺度感表现**：指数雾或大气散射近似、随高度变化的地表着色（岩石、雪线、高原、峡谷底）、以及一个远处地平线。让远处看起来极大，近处看起来有细节。
7. **HUD**：显示坐标、海拔、速度、已加载地块数、当前帧率。

## 自检（必须做，不修改源文件）

1. 用 `node --check` 检查两个 js 文件语法。
2. 写一个临时脚本（放在系统临时目录，不要放进工作区）验证确定性：对同一组坐标调用 `sampleHeight` 两次结果完全相同；对同一坐标用不同 step 求值仍返回同一高度。
3. 用临时脚本在 `-200km ~ +200km` 范围内采样若干剖面，统计最小/最大海拔与最大相对高差，确认相对高差达到 `20 km` 以上，并把统计结果写进最终报告。
4. 确认 `index.html` 不含任何 npm 依赖引用。
